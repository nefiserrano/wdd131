Overview

Purpose

The goal is to provide users with a real-time, visual representation of their spending habits to encourage better financial habits. The application calculates running totals and updates the interface instantly without requiring a page refresh.

Audience

This project is designed for students who needs a tool to track daily micro-expenses, such as groceries or subscriptions. It is ideal for someone looking to quickly log a purchase while on the go.

Dynamic elements

JavaScript listens for user interactions, such as clicking “Add” or “Filter”, to update the interface without requiring a page reload. It captures and stores input data, then uses a render function to dynamically generate and insert HTML elements (such as list items and buttons) into the page using template literals. This enables the interface to instantly recalculate the total balance through an updateTotal function and show or hide expenses based on selected filter criteria, ensuring the display always reflects the current data. Conditional logic is used to enhance visual feedback; for example, if the total balance exceeds the budget, it is displayed in red, otherwise in green. Each expense is represented as an object containing related properties such as amount and category, while all expenses are stored in an array. This structure allows for efficient data management and iteration, using array methods like filter and reduce to calculate totals and refine displayed results.
